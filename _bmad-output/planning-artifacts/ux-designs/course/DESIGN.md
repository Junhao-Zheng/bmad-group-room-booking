# 课题组预约界面设计

本设计由 AI 依据 PRD 拟定，是课程原型的界面约定，不代表用户访谈或人工验收。采用普通网页与少量渐进交互，视觉服务于查找时段和明确操作结果。

## 视觉约定

- 中文系统字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，正文不小于 16px，行高 1.5。
- 页面背景 `#f5f7f8`，正文 `#183343`，主要操作 `#126d65`，错误 `#a52b37`，信息底色 `#eef5f4`。主要按钮白字，文字与背景应具有可读对比。
- 内容最大宽度 1120px；桌面左右留白 32px，手机 16px。表单、列表和标题使用统一间距，不依赖装饰图片。
- 状态同时用文字和颜色表达：待开始、进行中、已结束、已取消；停用记录对应已撤销。

## 页面与组件

1. 顶部显示“课题组预约”、当前用户显示名、角色及退出入口。
2. 成员导航为“预约会议室”“我的预约”；管理员额外看到“会议室管理”“停用管理”“操作记录”。
3. 预约页上方为时间和人数查询表单，下方显示可用会议室及活动预约表单；日程作为独立区域提供房间与日期查询。
4. 个人记录以可扫描的列表展示，优先显示活动名、房间、时段和状态，取消操作有确认步骤。
5. 管理员表格在窄屏可横向滚动，页面本身不能出现横向溢出；主要表单纵向排列。
6. 输入项有明确 label、提示及错误消息。按钮通过键盘可访问，焦点轮廓可见，反馈区使用 `role=status` 或 `role=alert`。

## 验证条件

- 1280×800 与 390×844 视口下主流程可操作，页面没有水平溢出。
- 中文活动名称、长原因和空结果不会遮挡按钮。
- 业务状态可仅凭文字理解，禁用状态有原因提示。
- 控制台无未处理异常；正常与冲突结果均在页面清楚展示。
