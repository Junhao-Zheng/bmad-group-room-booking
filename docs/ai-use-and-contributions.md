# AI使用与贡献说明

本仓库由郑俊豪授权AI完成课程原型和过程材料。郑俊豪的已知真实贡献包括：提供课程讲义及教师免做实验B的更新；确定会议室预约题目、课题组使用对象；授权其余规则拟定、完整实施和GitHub交付。2026-11-13他进一步提供真实用房现状，并经澄清将单课题组范围修改为大组共享预约（D-005）；此后参与并确认具体业务规则和实施边界。2026-11-16郑俊豪确认小组另外两位成员为刘茜雅、黄欣；两人此前的实际参与尚无事实说明。[三人分工](team-contribution-plan.md)是后续任务安排，不计为已完成贡献。

AI承担需求拟定、BMAD工作流执行、架构比较、故事拆分、代码/测试生成、AI独立评审、实验协议与记录整理。独立AI代理分工只说明工具的执行方式，不替代学生参与。人工决策单独存于decision-log.md；AI架构备选否决和评审修订不得挪作“人类否决”。

工具环境：Codex桌面宿主、项目内官方BMAD6.12.1、Python/Flask/SQLite与Git、GitHub连接工具；浏览器验证使用隔离测试浏览器。精确服务端模型标识未由当前工具输出可核验值，记为未获知；实验两组继承同一会话模型配置且不手动切换。

业务规则中未取得课题组实证的信息标为假设。测试数据、示例名称和账号都是合成的；测试成绩仅引用实际运行记录。录屏如采用自动操作和合成解说，会在视频及说明中标注，不冒充学生现场讲解。

本次两个冲刺是压缩的实际增量，Git提交和状态事件保留真实时间。不将它们写成四周日历，不倒填教师M1/M2审批，不伪造实验收益或用户满意度。课程提交者仍需阅读、理解、核对真实人工材料并按教师要求展示自身参与。
